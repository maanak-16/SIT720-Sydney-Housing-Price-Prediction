## Data collection and provenance

The dataset contains 113 sold house records from Parramatta, Blacktown and Mosman: 33, 36 and 44 respectively. Each row retains an individual `realestate.com.au` property URL in `source_url`. The original suburb-level sold-listing pages are retained in `source_page_url` for collection context.

The dataset retains **sale year** rather than an artificial exact sale date. The earlier June-30 placeholder dates were removed because exact sale dates were not consistently verified across all records. `source_checked_date` records 18 September 2026 as the source-check date used for this finalisation pass.

## Run the notebook

Open the notebook in Jupyter or VS Code. Install the packages in `requirements.txt`, then run all cells from the beginning. The notebook expects `data/collected_sydney_housing.csv` to be present.

## Run the application

From the project directory:

```bash
pip install -r requirements.txt
python app.py
```

The application uses Gradio, loads `data/best_housing_model.joblib`, creates the same engineered features used during training and returns a predicted sale price.

## Part 5 comparison

The notebook evaluates ten held-out test properties using three approaches: the selected machine learning model, LLM-based estimates, and independent human estimates. The three sets of predictions are compared with the actual sale prices using MAE and RMSE.

The ten properties were selected independently of model prediction error to avoid selecting observations based on the model's performance.
